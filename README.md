> ### 1.判断函数np.all()和np.any()的用法
>
> **`np.all()`**：只有当数组中的**所有**元素**均为 True（或非零）时，才返回 `True`**；只要有一个 False就返回 `False`。
>
> **`np.any()`**：只要数组中出现**至少一个True（或非零）**，就返回 `True`；只有全为 `False` 时才返回 `False`。
>
> - ### 基本用法
>
> ```python
> np.all(a, axis=None)
> np.any(a, axis=None)
> #a可以是数组/列表/布尔条件。若a为前两者，则以1为标准来判断；若a为布尔条件，就以满足条件为标准来判断
> ```
>
> ### 2.np.argsort：获取排序后的索引
>
> - 普通的 `np.sort()` 会直接返回排好序的**数值**，而 `np.argsort()` 返回的是**数值在【原数组】中的位置（索引）**。
>
> ### 3.NumPy 切片
>
> ### 基本语法结构
>
> ```python
> arr[start : stop : step]
> ```
>
> - **`start`**：起始索引（**包含**该位置）。默认为 0。
> - **`stop`**：终止索引（**不包含**该位置，即前闭后开）。默认为数组长度。
> - **`step`**：步长。默认为 1。**正数表示从左到右，负数表示反向提取**。**-1表示数组反转**
>
> ### 一维数组切片
>
> ```python
> a = np.array([10, 20, 30, 40, 50, 60, 70])
> 
> print(a[1:5])     # [20, 30, 40, 50] （索引 1 到 4）
> print(a[:3])      # [10, 20, 30]     （前 3 个元素）
> print(a[4:])      # [50, 60, 70]     （从索引 4 开始到最后）
> print(a[::2])     # [10, 30, 50, 70] （隔一个取一个）
> print(a[::-1])    # [70, 60, 50, 40, 30, 20, 10] （数组反转）
> ```
>
> ### 二维数组切片（核心重点）
>
>  NumPy 允许使**用逗号分隔不同维度（区分行列）**：
>
> ```python
> arr[行切片, 列切片]
> #只有一个冒号表示遍历所有行或者所有列，逗号区分行和列
> ```
>
> | **操作需求**                  | **写法代码**        |
> | ----------------------------- | ------------------- |
> | **取第 1 行（降维为一维）**   | `M[1, :]` 或 `M[1]` |
> | **取第 2 列（降维为一维）**   | `M[:, 2]`           |
> | **取第 2 列（保持二维结构）** | `M[:, 2:3]`         |
> | **截取中间2×2子矩阵**         | `M[1:3, 1:3]`       |
> | **隔行隔列采样**              | `M[::2, ::2]`       |

> ### 2.np.dot语法
>
> #### （1）一维数组 vs 一维数组（最基础的“向量点积”）
>
> - 当两个输入都是一维数组时，`np.dot` 的作用是将两个数组**对应位置的元素相乘**，然后把所有的乘积**加在一起，变成一个单独的数字（标量）**。
>
> - **计算规则**：两个数组的长度必须完全一样。
>
> ```python
> import numpy as np
> 
> a = np.array([1, 2, 3])
> b = np.array([4, 5, 6])
> 
> result = np.dot(a, b)
> print(result) 
> # 计算过程: 1*4 + 2*5 + 3*6 = 4 + 10 + 18 = 32
> ```
>
> #### （2）多维数组 vs 一维数组
>
> - 当第一个数组是**多维**的（比如图像的三维数组），第二个数组是**一维**的（比如权重的 3 个数字），`np.dot` 的行为会变得非常智能：**它会拿第一个数组的“最后一维”，去和第二个数组做向量点积。**【这是图像灰度化代码能够一行搞定的核心原因】
>
> ```python
> # image 形状: (高度, 宽度, 3) 
> # weights 形状: (3,) -> 对应 [0.2989, 0.5870, 0.1140]
> 
> gray_image = np.dot(image, weights)
> ```
>
> **底层发生了什么？**
>
> 1. NumPy 看到 `image` 的最后面那个维度是 3（代表 R, G, B 三个通道），刚好和 `weights` 的长度 3 匹配上了。
> 2. 它会自动遍历整张图片里的每一个像素点。
> 3. 对于坐标为 `(y, x)` 的像素点，它会抽出这个点的 `[R, G, B]` 数组，和权重 `[0.2989, 0.5870, 0.1140]` 执行我们在**场景 1** 中讲过的**一维向量点积**
> 4. 计算出来的这个**单独的数字 Y（灰度亮度值）**，会替换掉原来那个拥有三个数字的彩色像素点（**第三维度数量从3变成1**）
> 5. 遍历完所有像素后，原本形状为 `(高度, 宽度, 3)` 的数组，最里面那个代表颜色的维度就被计算“压扁”了，变成了纯粹的**二维数组 `(高度, 宽度)`，也就是灰度图**
>
> ### 3. 二维数组 vs 二维数组（标准的“矩阵乘法”）
>
> ```python
> A = np.array([[1, 2], 
>               [3, 4]])  # 形状 (2, 2)
> 
> B = np.array([[5, 6], 
>               [7, 8]])  # 形状 (2, 2)
> 
> result = np.dot(A, B)
> print(result)
> # 输出:
> # [[19 22]   <- (1*5+2*7=19, 1*6+2*8=22)
> #  [43 50]]  <- (3*5+4*7=43, 3*6+4*8=50)
> ```
>
> ### 3. .shape(  )属性
>
> - `shape`是 NumPy 数组最核心的**属性**。它准确记录了这个数组在**不同维度上分别包含了多少个元素**。
>
> #### （1）调用 `数组.shape` 会返回一个 **元组 **。
>
> - **元组的长度**：代表这个数组有几个维度（是一维、二维还是三维）
> - **元组里的数字**：代表**每个维度具体有多长**
>
> > **⚠️ 新手防坑提示**：`.shape` 是一个“属性（Attribute）”而不是“方法（Method）”，所以调用它的时候**千万不要加括号**。写 `image.shape()` 会报错，正确的写法是 `image.shape`。
>
> #### （2）不同维度下的 `.shape` 拆解
>
> #### ① 一维数组（Vector 向量）
>
> ```python
> import numpy as np
> a = np.array([10, 20, 30, 40])
> print(a.shape)  # 输出: (4,)，表示这是一个 1 维数组，这一维有4个元素。
> ```
>
> #### ② 二维数组（矩阵 / 灰度图）
>
> 二维数组就像带有行和列的 Excel 表格。**永远记住它的顺序是：(行数, 列数)**，对应图像就是 **(高度, 宽度)**
>
> ```python
> b = np.array([
>     [1, 2, 3],
>     [4, 5, 6]
> ])
> print(b.shape)  # 输出: (2, 3)，元组长度为2表示这个数组有两个维度，且每个维度数量分别为2行3列
> ```
>
> #### ③ 三维数组（Tensor 张量 / 彩色图）
>
> 三维数组就像一个魔方，或者一本由很多页 Excel 表格叠起来的书。
>
> ```python
> # 假设这是你读取的彩色图片
> # print(image.shape) -> 输出: (300, 400, 3)
> ```
>
> - **第 0 维 (300)**：行数（图片的高度 Height）
> - **第 1 维 (400)**：列数（图片的宽度 Width）
> - **第 2 维 (3)**：深度/通道数（RGB 3 个颜色通道）



### 项目三：二维随机游走模拟器

- **目标**：避免使用 `for` 循环，纯利用 NumPy 的向量化操作解决复杂逻辑。

   **任务说明**：

1. 模拟一个醉汉在二维平面上的行走（起点为坐标 `[0, 0]`）。
2. 他一共走 1000 步，每一步只能随机向四个方向（上 `[0, 1]`、下 `[0, -1]`、左 `[-1, 0]`、右 `[1, 0]`）走一个单位。使用 `np.random.choice` 生成这 1000 步的方向。
3. 使用 `np.cumsum`（累积和）计算他每一步所在的实际坐标。
4. 计算他在游走过程中距离原点最远时的距离（欧几里得距离）。

- ### 核心知识点

> #### 1. `np.random.choice`：抽盲盒与掷骰子
>
> 这个函数的作用是从一个给定的一维数组中，**随机抽取**元素。
>
> **核心语法**： `np.random.choice(a, size=None, replace=True, p=None)`
>
> - **`a`**：你的“盲盒”池子（可以是一个**列表**或**数组**，**如果是1个数字，就会等同于从 `np.arange(N)`（即 0 到 N-1 的整数序列）中进行随机抽取）**
> - **`size`**：你要抽几次（比如抽 100 次就写 100）。
> - **`replace`**：是否可以重复抽取（放回抽样）。默认为 `True`。
> - **`p`**：每个元素被抽中的概率。如果不写，就是等概率盲抽。
>
> #### 2.np.cumsum()：它的作用是像记账本一样，把数组里的数字**挨个加起来**，并记录每一步的当前总和。
>
> ```python
> # 假设这是你 5 天里每天的盈亏记录
> daily_profit = np.array([10, -5, 20, 5, -10])
> 
> # 用 cumsum 计算每一天结束时的“总资产”
> total_assets = np.cumsum(daily_profit)
> 
> print(total_assets)
> # 输出: [ 10   5  25  30  20]
> ```

> #### 3.vstack和hstack
>
> ```python
> # 示例：hstack 左右拼接
> a = np.array([[1], [2]])  # (2, 1)
> b = np.array([[3], [4]])  # (2, 1)
> 
> print(np.hstack((a, b)))
> # 输出:
> # [[1 3]
> #  [2 4]]  <- 形状变成 (2, 2)
> ```
>
> ```python
> x = np.array([1, 2, 3])  # 形状 (3,)
> y = np.array([4, 5, 6])  # 形状 (3,)
> 
> res = np.vstack((x, y))
> print(res)
> # 输出:
> # [[1 2 3]
> #  [4 5 6]]   <- 变成了 (2, 3) 的二维数组
> ```
>
> | **函数**        | **全称**         | **拼接方向**         | **变化点**               | **硬性要求**                     |
> | --------------- | ---------------- | -------------------- | ------------------------ | -------------------------------- |
> | **`np.vstack`** | Vertical Stack   | **垂直（上下）拼接** | **行数变多**（纵向拉长） | 双方 **列数（Width）** 必须相同  |
> | **`np.hstack`** | Horizontal Stack | **水平（左右）拼接** | **列数变多**（横向拉宽） | 双方 **行数（Height）** 必须相同 |
